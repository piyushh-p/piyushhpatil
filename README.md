### What I've built

teams face: *where should we patch first?*
→ [View project](https://github.com/piyushhpatil/cve-exploit-predictor)

**JumpList Covert Channel (Original Research)**
Original research: a covert messaging system embedded inside Windows JumpLists in a shared AD
workspace. No custom malware. No obvious IOCs. Files the OS itself manages.
This technique has no prior public documentation.
→ [View research](https://github.com/piyushhpatil/jumplist-covert-channel)

**Home Active Directory Lab**
A continuously running attack-and-harden cycle against my own AD environment. I document every
attack and the detection/hardening that follows.
→ [View lab notes](https://github.com/piyushhpatil/home-ad-lab)
